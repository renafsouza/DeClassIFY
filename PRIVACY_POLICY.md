# Privacy Policy

This extension collects and processes limited user data for the purpose of classifying scientific documents and storing them in the user's Zotero library.

## Data Collected

- Zotero user ID and API credentials (via OAuth)
- Metadata from scientific PDF documents
- Classification tags or labels

## Use of Data

- Data is used solely to classify and organize documents in the user's Zotero account.
- No data is shared with third parties.
- No data is stored or logged outside the user's local browser and Zotero account.

## Third-Party Services

- The extension communicates with the **Zotero API** to store and retrieve user data.

## Data Access & Removal

- Users can revoke the extension's access at any time via [Zotero's authorized apps settings](https://www.zotero.org/settings/keys).

## Data Sharing

- We do **not** sell, rent, or share user data with any third party.
- This extension complies with the [Chrome Web Store User Data Policy](https://developer.chrome.com/docs/webstore/user_data/).

If you have any questions about this policy, please contact the developer.
